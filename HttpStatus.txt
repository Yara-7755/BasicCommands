1** Informational:

-100 (Continue) The server has received the request headers and the client should proceed.
-101 (Switching Protocols) The server is switching protocols as requested.
-102 (Processin) gThe server is processing the request .

2** Success :

-200 (OK) Request succeeded.
-201 (Created) Data was saved successfully — used after POST.
-204 (No Content)  Succeeded but nothing to return.
-202 request has been accepted for processing.

3** Redirection :

-300 (Multiple Choices) The request has more than one possible response.
-301 (Moved Permanently) The resource has been permanently moved to a new URL.
-302 (Found) The resource temporarily resides under a different URL.

4** Client Errors :

-400 (Bad Request) The server cannot process the request due to client error.
-404 (Not Found) The requested resource could not be found.
-401 (Unauthorized) You need to login first.
-404 (Not Found) Page or file doesn't exist.
-403 (Forbidden) The server understood the request but refuses to authorize it.

5** Server Errors:

-500 (Internal Server Error) Something broke in the server code .
-502 (Bad Gateway) Server got bad response from another server .
-503 (Service Unavailable) Server is down or overloaded.
-504 (Gateway Timeout) Server took too long to respond.
